# מערכת ניהול ותפעול – א. אמיר גז בע״מ

אב־טיפוס אינטראקטיבי בעברית וב־RTL לצורכי אפיון. כל הנתונים מקומיים ופיקטיביים; אין חיבור לשרת, סליקה, חשבוניות, WhatsApp, SMS, מפות או מערכות צד ג׳.

## הפעלה

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev
```

לאחר מכן פותחים: `http://127.0.0.1:5173/`

ממשק הנהג נפתח ישירות בכתובת: `http://127.0.0.1:5173/driver`

כדי להציג אותו בטלפון, מחברים את המחשב והטלפון לאותה רשת Wi-Fi ומריצים `npm.cmd run dev`. כתובת הרשת תופיע במסוף תחת `Network`; מוסיפים לה `/driver`. לדוגמה: `http://192.168.1.235:5173/driver`.

הפרויקט כולל Manifest, אייקון ו־Service Worker להתקנה כ־PWA. התקנה מלאה ממכשיר אחר דורשת בדרך כלל כתובת HTTPS; פתיחת הדמו ברשת המקומית עובדת גם ב־HTTP.

בדיקת Production Build:

```powershell
npm.cmd run build
npm.cmd run preview
```

## תרחיש מומלץ לפגישה

1. פתחו את הזמנה `#10421` של משפחת כהן.
2. לחצו **שייך למוחמד**, **אישור נהג**, **בדרך**, ואז **סמן בוצעה**.
3. בדקו בכרטיס מוחמד את **מלאי רכב** ואת **התחשבנות**.
4. חזרו להזמנה, לחצו **סמן שולם**, ואשרו את גביית ההדגמה.
5. חזרו לדשבורד וראו את עדכון הביצוע והגבייה.

State נשמר בזיכרון במהלך הסשן ומתאפס ברענון הדף.

## תרחיש הנהג

1. פתחו `/driver` ולחצו **התחל יום עבודה**.
2. פתחו את ההזמנה החדשה ובחרו **צא לדרך** או **סיום אספקה**.
3. אשרו מה סופק ומה חזר מהלקוח.
4. בחרו אמצעי תשלום ולחצו **סגור הזמנה**.
5. בדקו את עדכון המלאי, הקופה וההתחשבנות באפליקציית הנהג ובמערכת המשרד.
